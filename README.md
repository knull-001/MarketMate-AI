# MarketMate AI

An open-source marketing assistant for small businesses,
freelancers, independent creators, and online sellers.

## Features

- Audience Finder: suggest possible customer segments.
- Marketing Strategy: create positioning and action plans.
- Content Studio: draft captions and content calendars.
- Customer Outreach: prepare editable prospect messages.

## Technology

- Python and FastAPI
- HTML, CSS, JavaScript
- Optional Hugging Face Inference Providers integration
- Replaceable AI provider interface
- Demo mode without an AI API key

## Requirements

Python 3.10 or newer and pip.

## Setup

Create and activate a virtual environment if desired.

Install dependencies:

    python -m pip install -r requirements.txt

Start the server:

    python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Open the forwarded port 8000 in your development environment.

API documentation is available at /docs.

## Demo mode

Demo mode is the default. Its output is illustrative and
rule-based, not generated by a language model.

## Optional model integration

Install the dependencies, configure a private HF_TOKEN
environment variable, and set AI_PROVIDER=huggingface.

Set HF_MODEL to a compatible model supported by an available
Hugging Face Inference Provider.

Hosted inference requires internet access and is subject to
provider availability, model support, and free usage limits.
Do not commit secrets to this repository.

## Limitations

MarketMate suggests possible audiences and marketing actions.
It does not verify customer identities, measure actual demand,
scrape live market data, or guarantee business results.

The frontend requires the Python backend for generation.
GitHub Pages alone cannot run this backend.
